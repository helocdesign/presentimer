はじめに

PRESEN TIMER V1 は、発表の持ち時間をひと目で管理できるブラウザ用タイマーです。時間を決めて「開始」を押すだけで使えます。

  • できること: カウントダウン(2種類) / カウントアップ、残り5分・1分の色のお知らせと音、現在時刻・開始時間・終了時間の表示、よく使う時間の登録(3つ)、拡張モニターへの表示
  • 必要なもの: ブラウザ(Chrome または Edge を推奨)
  • 設定の保存: 時間や色などの設定はURLに保存されるので、ブックマークすれば次回も同じ設定で開けます

5番の時計が、発表中にいつも見るメインの数字です。ウィンドウの大きさに合わせて、時計は自動で大きくなったり小さくなったりします。「表示スタイル: 時間のみ」にすると、この時計だけが画面いっぱいに表示されます。「詳細設定」を開くと、音・モード・色などの設定が下に広がります。

基本の使い方

時間を選んで「開始」を押すだけで、タイマーが動き出します。

  1. 画面下の「時・分・秒」プルダウンで、発表時間を選びます(最大で 3 時間。初期設定は 30 分)。
  2. 「開始」を押す(または Space キー)と、カウントが始まります。
  3. 途中で止めるときは「一時停止」、続けるときは「再開」。最初からやり直すときは「リセット」を押します。

「-1分」「+1分」で、表示中の時間を1分ずつ調整できます。モードを「カウントアップ」にすると、時計は 0 から増えていき、タイトル欄は「経過時間」になります。

時刻の表示(現在時刻・開始時間・終了時間)

メッセージ枠の左右に、時刻を表示します。発表の終わる時刻をひと目で確認できます。

表示内容
現在時刻(左)いまの時刻を、時:分:秒で表示します。
開始時間(右)最初に「開始」を押した時刻で止まります。一時停止して再開しても変わりません。
終了時間(右)開始した時刻に、設定した時間を足した時刻です。
  • 開始前は、開始時間・終了時間とも 00:00 と表示されます。
  • 終了時間になると、現在時刻の表示がその時刻で止まります。
  • 「リセット」を押すと、開始時間・終了時間は 00:00 に戻り、現在時刻はまた動き出します。
  • 「+1分」「-1分」を押しても、終了時間は変わりません。
  • 表示スタイルが「シンプル」「時間のみ」のときは、この時刻の表示は隠れます。

メモリー(よく使う時間を登録)

よく使う時間を M1〜M3 に3つまで登録して、ボタン1つで呼び出せます。

  1. 時・分・秒のプルダウンで、登録したい時間を設定します。
  2. 右側のプルダウンで M1〜M3 のどれかを選び、「登録」を押します。
  3. 真ん中の M1〜M3 に、その時間が表示されます(1時間以上は 01:30:00 の形式)。
  4. 次からは、M1〜M3 を押すだけで、タイマーがその時間に切り替わります。
  • 同じ番号にもう一度登録すると、上書きされます。
  • いま設定している時間と同じボタンは、枠が緑色になります。
  • 動作中に M1〜M3 を押すと、新しい時間に切り替わり、タイマーはリセットされます。

色と音でお知らせ

モードが「カウントダウン2(警告表示あり)」のとき、残り5分で黄色、残り1分で赤に変わります。0:00になると音が3回鳴ります。

  • モードは3種類です。「カウントダウン1」は残り時間が減っても色が変わりません。「カウントダウン2」は上の図のように色が変わります。「カウントアップ」は下の説明のとおりです。
  • 音は、詳細設定の「警告(1回)」「危険(2回)」で決めた残り時間(初期値は 1:00 と 0:10)に1回・2回鳴り、0:00 で3回鳴ります。色の変化とは別に設定します。
  • 音は初期設定で OFF です。詳細設定で「音: ON」にすると鳴ります。
  • 0:00 を過ぎても止まらず、「-00:05」のようにマイナス表示で赤く点滅し続けます(カウントダウン1でも同じです)。
  • カウントアップでは、設定した時間までの残りが「警告(1回)」「危険(2回)」の時間になると、数字とゲージがオレンジ・赤に変わります。

拡張モニター(2画面で使う)

手元のPCで操作しながら、拡張モニター(プロジェクターなど)に時計だけを大きく映せます。

  1. 画面下の「拡張モニター」ボタンを押します。時計・ゲージ・メッセージだけを表示する小窓が開きます。
  2. Chrome または Edge を HTTPS で開き、「画面の管理」を許可していると、小窓が拡張モニター側に開き、自動で全画面になります(ブラウザの制限で全画面にならないときは手順 3)。
  3. 自動で移動しないときは、小窓を拡張モニターへドラッグし、もう一度「拡張モニター」を押します。
  4. 終わるときは Esc キーで全画面を解除し、小窓を閉じます。

小窓は手元の操作と同期します。開始・一時停止や色の変更は、すべて手元のPC側で行います。

Introduction

PRESEN TIMER V1 is a browser-based timer that lets you keep track of your speaking time at a glance. Set a time and press Start — that is all it takes.

  • What it does: countdown (2 types) / count up, color alerts at 5 minutes and 1 minute left plus sound alerts, current / start / end time display, saved times (3 slots), and display on an extended monitor
  • What you need: a browser (Chrome or Edge recommended)
  • Saved settings: time, colors and other settings are stored in the URL, so bookmark it to reopen with the same settings next time

The clock (5) is the main number you watch while presenting. It automatically grows or shrinks to fit the window. With “Style: Time Only”, only this clock fills the screen. Open “Settings” to expand the sound, mode and color options below.

How to use

Choose a time and press “Start” — the timer begins.

  1. Use the hour / minute / second pulldowns at the bottom to choose your speaking time (up to 3 hours; the default is 30 minutes).
  2. Press “Start” (or the Space key) to begin counting.
  3. To stop partway, press “Pause”; to continue, press “Resume”. To start over, press “Reset”.

“-1 min” and “+1 min” adjust the displayed time one minute at a time. In “Count up” mode the clock counts up from 0 and the title field reads “Elapsed Time”.

Time display (current, start and end time)

Times are shown on both sides of the message box, so you can see at a glance when your talk will end.

DisplayWhat it shows
Current Time (left)The time right now, in h:m:s.
Start Time (right)Stays at the time you first pressed “Start”. It does not change when you pause and resume.
End Time (right)The start time plus the time you set.
  • Before you start, both Start Time and End Time show 00:00.
  • When the end time is reached, the Current Time display stops at that time.
  • Press “Reset” to return Start Time and End Time to 00:00; Current Time starts moving again.
  • “+1 min” and “-1 min” do not change the End Time.
  • With the “Simple” or “Time Only” style, these time displays are hidden.

Memory (save frequently used times)

Save up to three frequently used times in M1–M3 and recall each with one press.

  1. Set the time you want to save with the hour / minute / second pulldowns.
  2. Choose M1–M3 in the pulldown on the right and press “Save”.
  3. The time appears on the M1–M3 button in the middle (shown as 01:30:00 for an hour or more).
  4. From then on, just press M1–M3 to switch the timer to that time.
  • Saving to the same number again overwrites it.
  • The button matching the time currently set gets a green border.
  • Pressing M1–M3 while the timer is running switches to the new time and resets the timer.

Color and sound alerts

In “Countdown 2 (with warnings)” mode, the clock turns yellow at 5 minutes left and red at 1 minute left. Three beeps sound at 0:00.

  • There are three modes. “Countdown 1” never changes color as time runs down. “Countdown 2” changes color as in the figure above. “Count up” is described below.
  • Sounds play at the times set by “Warning (1 beep)” and “Danger (2 beeps)” in Settings (defaults: 1:00 and 0:10), and three beeps sound at 0:00. These are set separately from the color changes.
  • Sound is OFF by default. Turn it on with “Sound: ON” in Settings.
  • Past 0:00 the timer keeps going, showing a minus sign like “-00:05” and blinking red (also in Countdown 1).
  • In count-up mode, the digits and gauge turn orange / red when the time left until your set time reaches the “Warning (1 beep)” / “Danger (2 beeps)” times.

Extended Monitor (using two screens)

Operate from the PC in front of you while showing only the clock, large, on an extended monitor (projector, etc.).

  1. Press the “Extended Monitor” button at the bottom of the screen. A small window showing only the clock, gauge and message opens.
  2. If you open the page over HTTPS in Chrome or Edge and allow “window management”, the small window opens on the extended monitor and goes fullscreen automatically (if the browser does not allow fullscreen, go to step 3).
  3. If it does not move on its own, drag the small window to the extended monitor and press “Extended Monitor” again.
  4. When you finish, press the Esc key to leave fullscreen, then close the small window.

The small window stays in sync with your controls. Start, pause and color changes are all made on your own PC.

Common problems and what to do.

No soundSound is OFF by default. Set “Sound: ON” in Settings, and use “Test Sound” to check that it plays.
The color does not change as time runs downIn “Countdown 1” mode the color never changes. Choose “Countdown 2 (with warnings)” under “Mode” in Settings.
A message asks you to allow pop-upsAllow pop-ups for this page in your browser.
