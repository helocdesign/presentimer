PRESEN TIMER V1 かんたんマニュアル

produced by helocdesign ・ 2026-10-05

はじめに

PRESEN TIMER V1 は、発表の持ち時間をひと目で管理できるブラウザ用タイマーです。時間を決めて「開始」を押すだけで使えます。

  • できること: カウントダウン / カウントアップ、残り1分・10秒の色と音のお知らせ、よく使う時間の登録(3つ)、拡張ディスプレイへの表示
  • 必要なもの: ブラウザ(Chrome または Edge を推奨)
  • 設定の保存: 時間や色などの設定はURLに保存されるので、ブックマークすれば次回も同じ設定で開けます

基本の使い方

時間を選んで「開始」を押すだけで、タイマーが動き出します。

  1. 画面下の「時・分・秒」プルダウンで、発表時間を選びます(最大で 3 時間)。
  2. 「開始」を押す(または Space キー)と、カウントが始まります。
  3. 途中で止めるときは「一時停止」、続けるときは「再開」。最初からやり直すときは「リセット」を押します。

「-1分」「+1分」で、表示中の時間を1分ずつ調整できます。モードを「カウントアップ」にすると、時計は 0 から増えていき、タイトル欄は「経過時間」になります。

メモリー(よく使う時間を登録)

よく使う時間を M1〜M3 に3つまで登録して、ボタン1つで呼び出せます。

  1. 時・分・秒のプルダウンで、登録したい時間を設定します。
  2. 右側のプルダウンで M1〜M3 のどれかを選び、「登録」を押します。
  3. 真ん中の M1〜M3 に、その時間が表示されます(1時間以上は 01:30:00 の形式)。
  4. 次からは、M1〜M3 を押すだけで、タイマーがその時間に切り替わります。
  • 同じ番号にもう一度登録すると、上書きされます。
  • いま設定している時間と同じボタンは、枠が緑色になります。
  • 動作中に M1〜M3 を押すと、新しい時間に切り替わり、タイマーはリセットされます。

色と音でお知らせ

残り1分でオレンジ、残り10秒で赤に変わり、0:00になると音が3回鳴ります。

  • 色が変わるタイミング(警告・危険)は、詳細設定で変えられます(初期値は 1:00 と 0:10)。ゲージも同じ色になります。
  • 音は初期設定で OFF です。詳細設定で「音: ON」にすると鳴ります。
  • 0:00 を過ぎても止まらず、「-00:05」のようにマイナス表示で赤く点滅し続けます。
  • カウントアップでも、設定した時間までの残りで同じように色と音が変わります。

プレゼンテーションモード(2画面で使う)

手元のPCで操作しながら、拡張ディスプレイ(プロジェクターなど)に時計だけを大きく映せます。

  1. 右上の「プレゼンテーションモード」ボタンを押します。時計・ゲージ・メッセージだけを表示する小窓が開きます。
  2. Chrome または Edge を HTTPS で開き、「画面の管理」を許可していると、小窓が拡張ディスプレイ側に開き、自動で全画面になります(ブラウザの制限で全画面にならないときは手順 3)。
  3. 自動で移動しないときは、小窓を拡張ディスプレイへドラッグし、もう一度「プレゼンテーションモード」を押します。
  4. 終わるときは Esc キーで全画面を解除し、小窓を閉じます。

小窓は手元の操作と同期します。開始・一時停止や色の変更は、すべて手元のPC側で行います。

キーボード操作

2つのキーだけ覚えれば、発表中にマウスを使わず操作できます。

キー動作
Space開始 → 一時停止 → 再開(開始ボタンと同じ。メッセージ欄などの入力中は効きません)
Esc全画面表示を解除。「時間のみ」表示のときは、元の「フル」表示に戻ります

こまったときは

よくある症状と対処をまとめました。

症状対処
音が鳴らない音の初期設定は OFF です。詳細設定で「音: ON」にして、「音の確認」で鳴ることを確かめてください。
残り1分になっても色が変わらない詳細設定の「警告(1回)」「危険(2回)」の時間を確認してください(0:00にすると無効になります)。
「ポップアップを許可してください」と出るブラウザのポップアップブロックを、このページについて許可してください。
プレゼンテーションモードが拡張ディスプレイに自動で出ない自動で移動するのは、HTTPS で開き、Chrome / Edge で「画面の管理」を許可した場合だけです。それ以外は、開いた小窓を拡張ディスプレイへドラッグし、もう一度ボタンを押してください。
iPhone / iPad で全画面表示にならないiOS のブラウザは全画面表示機能に対応していないため、画面いっぱいに広げる簡易表示になります。
登録した時間(M1〜M3)が出てこない登録した時間は、使っているブラウザに保存されます。別のブラウザやパソコンでも使いたいときは、登録後のURLごとブックマークし、そのURLを開いてください(登録した時間もURLに含まれます)。
設定がもとに戻る設定はURLに保存されます。同じURLで開くか、ブックマークしてください。音の ON / OFF だけは保存されず、開くたびに OFF から始まります。
